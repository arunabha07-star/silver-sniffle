DHEROS BIRTHDAY SURPRISE WEBSITE

FILES
- index.html: all six interactive screens
- style.css: layout, original CSS bear characters and animations
- script.js: page navigation, password, music, candles and cake-cutting
- assets/our-photo.jpg: the photo you uploaded, used on the final screen
- qr-generator.html: create a working QR code after the site has a public URL

RUN LOCALLY
Extract the ZIP and open index.html in a browser. Password: dheros.
Music starts only after the visitor taps the Music button (browsers block autoplay).
The music is an original soft music-box style tune generated in the browser.

MAKE THE QR CODE WORK ON SOMEONE ELSE'S PHONE
A QR code needs a public website address. A local file address only works on your own computer.
1. Upload this folder to a static host such as GitHub Pages, Netlify, or your own web hosting.
2. Copy the public URL (for example, https://yourname.netlify.app).
3. Open qr-generator.html, paste the public URL and press Generate QR Code.
4. Download/print the QR. The QR opens the website; the landing page itself has the “Click for a surprise” button.

The bear drawings are original CSS-made cute bear characters, not copied character artwork.
